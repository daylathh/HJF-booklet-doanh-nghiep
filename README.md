# HANU Job Fair 2026 Flipbook

This is the complete GitHub Pages site bundle.

## Files
- `index.html` — flipbook page with mobile 1-page / 2-page modes and edge navigation buttons.
- `page-01.jpg` through `page-28.jpg` — high-resolution page images used by `index.html`.

## Publish with GitHub Pages
1. Extract this archive and upload all files in this folder to the root of the new repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then save.
4. Open the published Pages URL after the build completes.
